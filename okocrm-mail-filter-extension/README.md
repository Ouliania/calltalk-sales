# 🛡️ Расширение: OkoCRM Mail Filter & Search (Call-Talk)

Специальное расширение для браузера (Chrome, Яндекс.Браузер, Edge), решающее две ключевые боли в OkoCRM:
1. **Скрывает прогревочные письма Trigga** по кодам в теле писем, не трогая саму почту на сервере Яндекса (доставляемость и прогрев Trigga работают на 100%).
2. **Добавляет живой поиск по письмам**, которого нет в стандартном интерфейсе OkoCRM.

---

## 🚀 Как установить расширение (1 минута):

1. Откройте в браузере (Chrome или Яндекс.Браузер) страницу расширений:
   * Для Google Chrome: `chrome://extensions`
   * Для Яндекс.Браузера: `browser://tune` или `chrome://extensions`
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
3. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите папку:
   `/Users/ulyana/CALL TALK/okocrm-mail-filter-extension`
5. Готово! Расширение установлено.

---

## 🎯 Как пользоваться в OkoCRM:

1. Перейдите в OkoCRM в раздел **«Почта»**:
2. Вверху появится аккуратная панель:
   * **Тумблер «Скрыть прогрев»:** включает/выключает скрытие писем ботов.
   * **Счетчик:** показывает, сколько писем ботов скрыто и сколько реальных клиентов найдено.
   * **Строка поиска:** мгновенно фильтрует письма по теме, имени отправителя, email или тексту.
   * **Кнопка «⚙️ Коды»:** позволяет в любой момент вставить новые коды прогрева Trigga (каждый с новой строки).

---

## 🔒 Безопасность доставляемости:
* Письма **НЕ** перемещаются в другие папки на Яндексе.
* Письма **НЕ** удаляются.
* Сервис Trigga видит все письма в Inbox в штатном режиме, доставляемость не страдает.
